# 🌍 World 1: The Local Sandbox

**Goal:** Prove that vibe-coding is safe, fast, and requires no special software. You will go from a simple prompt to a functioning local `.html` file that you can run on your own machine, regardless of your operating system.

**The Setting:** A glowing, grid-lined digital workshop where raw text floats in the air before solidifying into code.

**Your Guide:** The Alchemist (A wise, calm figure surrounded by floating curly brackets and `< / >` tags).

---

## 🗡️ Quest 1: The First Spark (Generation)

*The Alchemist says: "The raw materials of your curriculum are heavy, but words are light. Speak your precise intent into the Canvas, Vibe-Coder. Let us see what interactive spark you can conjure from nothing."*

**Action:** 
Formulate a structured prompt in the AI of your choice (we recommend Google Canvas) to generate a basic interactive activity using your current curriculum materials. 

Copy the blueprint prompt below, fill in the bracketed information, and paste it into the AI:

> **The Blueprint Prompt:**
> Act as an expert educational web developer and instructional designer. Build a highly engaging, interactive [INSERT ACTIVITY TYPE: e.g., drag-and-drop vocabulary matcher / clickable flashcard grid / self-grading quiz] for my students.
> 
> **Topic & Target Audience:** 
> [INSERT GRADE LEVEL AND SPECIFIC TOPIC]
> 
> **Source Material:**
> Only use the following curriculum text to generate the questions and answers: 
> [PASTE YOUR VOCABULARY LIST, READING PASSAGE, OR CURRICULUM TEXT HERE]
> 
> **Technical Constraints:**
> 1. Output the entire activity as a single, self-contained vanilla HTML file.
> 2. All CSS and JavaScript must be inline within the file. 
> 3. Do not reference or link to any external local files (no local .jpg, .png, or .css files). Use native CSS styling, CSS shapes, or HTML text/emojis for all visual elements.
> 4. Ensure the layout is responsive and scales gracefully for both desktop and mobile screens.

## 🛠️ Quest 2: The Iteration (Editing)

*The Alchemist says: "A functioning artifact, yes, but it lacks your signature. Do not touch the syntax with your bare hands! Command the Canvas to paint it anew. Adjust the difficulty, shift the palette, and make it yours."*

**Action:** 
Prompt the AI to modify the code it just generated—adjust the difficulty, change the colors, or fix a layout issue—without touching the syntax directly. 

Try pasting one of these iteration prompts into your AI chat:
* **The Aesthetic Shift:** "The activity works, but the design is a bit bland. Please update the CSS to use a [synthwave retro arcade / clean modern minimalist] aesthetic."
* **The Difficulty Dial:** "Let's increase the challenge. Please add a visible countdown timer. If the student successfully completes the activity, display a victory message with a reset button."

## 💾 Quest 3: The Desktop Deployment (Local Execution)

*The Alchemist says: "The magic is currently bound to the cloud, but true power rests on your own machine. Extract the raw plain text, save it locally, and awaken the file in your own browser."*

**Action:** 
Copy the raw code generated by the AI, save it locally to your computer, and open it in a web browser. Follow the path for your specific device:

*   **macOS (Primary Path):** 
    1. Open **TextEdit**. 
    2. Go to `TextEdit > Settings` (or Preferences). Under the "New Document" tab, select **Plain text**. Uncheck "Smart quotes" and "Smart dashes." 
    3. Paste your code into a new document. 
    4. Verify it is plain text (`Format > Make Plain Text`), and save the file as `my-activity.html` to your Desktop.
*   **Windows Path:** 
    1. Open **Notepad**.
    2. Paste your code.
    3. Go to `File > Save As`. Change "Save as type" to **All Files (*.*)**.
    4. Save the file as `my-activity.html` to your Desktop.
*   **Chromebook Path:** 
    1. Open the built-in **Text** app (or a basic Chrome extension).
    2. Paste your code and save the file as `my-activity.html`.

Once saved, simply double-click the `.html` file (or drag it into an open Chrome/Safari window) to play your game locally!
